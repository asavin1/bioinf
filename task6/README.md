# Отчёт по заданию: Изучение взаимодействия альбутерола с бета-2 адренорецептором

## Задание
Изучить взаимодействие препарата **Альбутерол** (Сальбутамол) с мишенью **Бета-2 адренорецептор** (PDB ID: `1GQ4`) с использованием методов биоинформатики.

## Исходные данные
- **Лиганд**: Альбутерол (Сальбутамол)
- **SMILES лиганда**: `CC(C)(C)NCC(O)C1=CC(CO)=C(O)C=C1`
- **Таргет**: Бета-2 адренорецептор (Beta-2 Adrenergic Receptor, β2AR)
- **PDB ID таргета**: `1GQ4`

### 1. Информация о препарате (лиганде)

#### a. Действующее вещество
**Альбутерол (Сальбутамол)** — действующее вещество. Химическое название: (RS)-4-[2-(tert-Butylamino)-1-hydroxyethyl]-2-(hydroxymethyl)phenol.

#### b. Область применения
Альбутерол применяется для:
- Быстрого купирования и профилактики приступов **бронхиальной астмы**
- Лечения обратимого бронхоспазма при **хронической обструктивной болезни лёгких (ХОБЛ)**
- Профилактики бронхоспазма, вызванного физической нагрузкой

#### c. Молекулярный механизм действия
Альбутерол является **селективным агонистом бета-2 адренорецепторов (β2-адренорецепторов)**. Механизм действия:
1. **Связывание с рецептором**: Альбутерол связывается с внеклеточной частью β2-адренорецептора
2. **Активация сигнального каскада**: Связывание активирует Gs-белок, который стимулирует фермент аденилатциклазу
3. **Образование цАМФ**: Аденилатциклаза увеличивает внутриклеточный уровень циклического аденозинмонофосфата (цАМФ)
4. **Расслабление мышц**: Повышенный уровень цАМФ активирует протеинкиназу A, вызывая расслабление гладкой мускулатуры бронхов
5. **Расширение дыхательных путей**: Расслабление гладких мышц приводит к бронходилатации

Альбутерол обладает **селективностью** к β2-рецепторам, что минимизирует воздействие на β1-рецепторы сердца.

#### Химические данные
- **SMILES**: `CC(C)(C)NCC(O)C1=CC(CO)=C(O)C=C1`
- **Молекулярная формула**: C₁₃H₂₁NO₃
- **Молекулярная масса**: 239.31 г/моль

#### Целевой белок
- **Название**: Бета-2 адренорецептор

### 4. Анализ сайта связывания

Бета-2 адренорецептор относится к семейству GPCR (рецепторы, сопряжённые с G-белком). Активный сайт рецептора расположен в трансмембранной области и образован семью трансмембранными α-спиралями.

**Ключевые аминокислотные остатки** активного центра, важные для связывания агонистов:
- **Asp113** (трансмембранный домен 3) — формирует ионную связь с аминогруппой лиганда
- **Ser203** и **Ser207** (трансмембранный домен 5) — образуют водородные связи с гидроксильными группами лиганда
- **Phe290** (трансмембранный домен 6) — участвует в гидрофобных взаимодействиях

### 5. Теоретические аспекты взаимодействия альбутерола с рецептором

На основе анализа структуры рецептора и лиганда можно предсказать характерные взаимодействия:

1. **Ионное взаимодействие**: Протонированная аминогруппа альбутерола может образовывать ионную пару с карбоксильной группой Asp113.

2. **Водородные связи**: Гидроксильные группы катехольного кольца альбутерола могут формировать водородные связи с гидроксильными группами Ser203 и Ser207.

3. **Гидрофобные взаимодействия**: Трет-бутильная группа и ароматическое кольцо альбутерона могут взаимодействовать с гидрофобными остатками, включая Phe290.

4. **Стереоселективность**: (R)-энантиомер альбутерола обладает значительно большей активностью, чем (S)-энантиомер, что связано с оптимальным пространственным соответствием активному центру рецептора.

### 6. Выводы

1. **Структурная основа взаимодействия**: Бета-2 адренорецептор представляет собой типичный GPCR с активным сайтом, расположенным в трансмембранной области. Ключевые остатки Asp113, Ser203, Ser207 и Phe290 образуют специфический карман для связывания агонистов.

2. **Комплементарность структур**: Молекула альбутерола содержит функциональные группы, комплементарные активному центру рецептора: аминогруппу для взаимодействия с Asp113, гидроксильные группы для связывания с Ser203/Ser207, и гидрофобные фрагменты для взаимодействия с Phe290.

3. **Селективность действия**: Специфичность альбутерола к β2-адренорецепторам обеспечивается оптимальным сочетанием ионных, водородных и гидрофобных взаимодействий, характерных для данного подтипа рецепторов.

4. **Значение для фармакологии**: Понимание структурных основ взаимодействия альбутерола с бета-2 адренорецептором важно для разработки новых бронходилататоров с улучшенными свойствами (большей селективностью, продолжительностью действия, меньшими побочными эффектами).

Таким образом, проведённый анализ структурных особенностей бета-2 адренорецептора и молекулы альбутерола позволяет понять молекулярные основы фармакологического действия этого важного бронходилататора.
