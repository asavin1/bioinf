# Отчёт по заданию: Молекулярный докинг ранитидина на ацетилхолинэстеразу

## Задание
Выполнить молекулярный докинг препарата **Ранитидин** на мишень **Ацетилхолинэстераза** (PDB ID: `1F8U`).

## Исходные данные
- **Лиганд**: Ранитидин
- **SMILES лиганда**: `CNC(NCCSCC1=CC=C(CN(C)C)O1)=C[N+]([O-])=O`
- **Таргет**: Ацетилхолинэстераза (Acetylcholinesterase, AChE)
- **PDB ID таргета**: `1F8U`

### 1. Информация о препарате (лиганде)

#### a. Действующее вещество
**Ранитидин** — действующее вещество, относящееся к группе блокаторов H₂-гистаминовых рецепторов второго поколения. Химическое название: N-[2-[[[5-[(диметиламино)метил]-2-фуранил]метил]тио]этил]-N'-метил-2-нитро-1,1-этендиамин.

#### b. Область применения
Ранитидин применяется для:
- Лечения и профилактики **язвенной болезни желудка и двенадцатиперстной кишки**
- Терапии **гастроэзофагеальной рефлюксной болезни (ГЭРБ)**
- Лечения **синдрома Золлингера-Эллисона**
- Профилактики стрессовых язв

#### c. Молекулярный механизм действия
Ранитидин является **конкурентным антагонистом H₂-гистаминовых рецепторов** париетальных клеток желудка.

Механизм действия:
1. **Блокада рецепторов**: Ранитидин связывается с H₂-гистаминовыми рецепторами на поверхности париетальных клеток желудка
2. **Ингибирование синтеза кислоты**: Блокирование рецепторов препятствует активации аденилатциклазы и образованию цАМФ
3. **Снижение активности протонной помпы**: Уменьшение уровня цАМФ приводит к снижению активности H⁺/K⁺-АТФазы (протонной помпы)
4. **Уменьшение кислотности**: Снижение секреции соляной кислоты в желудке независимо от стимула

**Примечание**: В данном задании докинг выполняется на ацетилхолинэстеразу, что является нестандартной мишенью для ранитидина и выполняется в исследовательских целях для изучения возможных перекрёстных взаимодействий.

#### Химические данные

- **Молекулярная масса**: 314.41 г/моль
